# flutter_tipkit

Contextual feature tips for Flutter.

| Package | What it is |
|---|---|
| [flutter_tipkit](packages/flutter_tipkit) | Tips with rules, events, a display frequency and groups, shown inline or as popovers. |
| [flutter_tipkit_shared_preferences](packages/flutter_tipkit_shared_preferences) | A `shared_preferences` datastore, so tip state survives app restarts. |

Run `flutter pub get` in the repository root. The packages form a
[pub workspace](https://dart.dev/tools/pub/workspaces), so they resolve to each
other locally.
